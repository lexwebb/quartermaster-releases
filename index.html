01 · why

You started six agents across four repos before lunch. One finished an hour ago. One has been sitting on a permission prompt since 10:40. Two PRs need a review and someone asked you a question in Slack.

● watchesEvery session, every repo.Claude, Codex, Gemini, Ollama, agy — including the ones you started by hand. Fleetwatch re-indexes every 3 minutes with zero LLM calls.
◆ asksOne inbox for what needs you.Permission prompts, finished results, red CI, stalled reviews. Desktop when you're here, Slack when you're away — never both.
◇ delegatesBriefs, not keystrokes.Ask the fleet chat for something and it queues a new session with a standalone brief. Nothing runs until you press y.

03 · fleet chat

The one agent that refuses to write code.

The chat is a persistent master session over ACP. It sees the whole fleet through a read-only MCP server, and the harness refuses edits and mutating shell commands. Ask it to do something and it writes a brief for a new session — in a fresh worktree, with spend limits — then waits for you.

what_nowone ranked list of what you can do next
get_fleetevery session, live, by status
add_backlog_item"idea: …" goes to later, not to a spawn
⌃spacedictate; whisper runs on your machine
04 · local-first

One folder. One loopback port. No account.

Config, state and the memory brain live in ~/.quartermaster. The dashboard binds to 127.0.0.1. Embeddings and transcription run locally, so review text never leaves the machine. Want it on your phone? Put it behind tailscale serve, allowlisted by login.

~/.quartermaster
├─ config.json       every key optional
├─ brain.sqlite      decisions · rag memory
├─ workflows/        bowlyn yaml overlays
├─ models/           whisper · ollama
├─ logs/             7 days kept
└─ state/
   ├─ repos/         bare-clone cache
